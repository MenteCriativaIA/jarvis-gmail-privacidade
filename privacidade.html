Política de privacidade — JARVIS Gmail leitura

Atualizada em 21/11/2026.

Quem usa e para quê

Este aplicativo é uma ferramenta pessoal, usada apenas pelo seu próprio desenvolvedor, na conta Gmail dele. Ele lê mensagens da caixa de entrada para listar, uma vez por dia, o que exige ação nos projetos do dono. Ninguém além do dono usa o aplicativo nem vê os resultados.

Quais dados são acessados

O aplicativo pede apenas a permissão de leitura do Gmail (gmail.readonly). Ele lê remetente, assunto, data e, quando necessário, o texto das mensagens. Não envia, apaga, arquiva nem altera nenhuma mensagem.

Onde os dados ficam

Os dados lidos e os resumos ficam somente no computador do dono, em arquivos locais que não são enviados a nenhum repositório nem serviço de armazenamento. O aplicativo não tem servidor próprio.

Compartilhamento e uso

Os dados não são vendidos, compartilhados com terceiros, usados para publicidade nem usados para treinar modelos de inteligência artificial. Para classificar ou resumir mensagens, o dono pode pedir ao assistente de IA que ele mesmo usa (Claude, da Anthropic, na conta do próprio dono) que leia o conteúdo no computador dele, apenas para entregar o resultado a ele.

O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Como revogar o acesso e apagar os dados

O dono pode revogar a permissão a qualquer momento em myaccount.google.com/permissions e apagar os arquivos locais do aplicativo.
